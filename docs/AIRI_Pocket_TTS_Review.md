# AIRI Pocket TTS inference review

> **Implementation status (Batches 1–4 complete):** All four batches below have been implemented across `contract.ts`, `pocket_model_store.ts`, `pocket_onnx_engine.ts`, `worker.ts`, `adapters/pocket-tts.ts`, `pocket-audio-utils.ts`, `registry/speech.ts`, `speech-playground.vue`, and `pocket-tts-local.vue` (verified via `pocket-audio-utils.test.ts` and `stage-ui`/`stage-pages` `vue-tsc --noEmit`).
>
> **Verified device benchmarks (2026-11-17):** Cold boot **2496 ms TTFA / 0.987 RTF** (5293 ms latency, 5.36 s audio); warm runs **588 ms / 579 ms TTFA** (median **583.5 ms**) and **0.628 / 0.624 RTF** (median **0.626 RTF**).

**Fix bundle selection and clone-cache identity first. Then expose the audio Pocket already produces.** A French selection can generate with the English model. Even after a successful French load, a saved English clone embedding can win over the French worker cache. Either defect undermines a speed or listening comparison. For conversational latency, the decoder and worker already emit early audio. The shortest path to hearing it is in the adapter, provider and playground.

Reviewed `dasilva333/airi` main at [`395f313ee`](https://github.com/dasilva333/airi/commit/395f313ee99ad777e219e10d620e5089876d846e). The source links below are pinned to that revision. Isolated probes ran the checked-in registry factory, adapter, worker handlers, conditioning code and decoder schedule with substituted I/O or model sessions. Published assets were checked separately. Browser RTF, real first-audio times, audible gaps and speaker similarity remain device measurements. This review changes no repository files.
